# Milestone v2.0: User System + Monetization

**Status:** SHIPPED 2026-02-02
**Phases:** 4-10
**Total Plans:** 23

## Overview

Transform the anonymous v1 MVP into a credible SaaS product by adding authentication (Supabase Auth), database persistence (Supabase Postgres + Drizzle), post history, usage-based monetization (Stripe), and a user dashboard. The roadmap preserves the existing anonymous workflow while adding progressive authentication—users experience value before signup, then upgrade to save their work. Phases follow natural dependencies: Database → Auth → History → Usage Limits → Payments → Dashboard.

## Milestone Summary

**Key Decisions:**

- Supabase Auth over Clerk (unified with existing Supabase DB)
- Custom sign-in/sign-up forms with Lithuanian UI
- Cursor-based pagination for post history
- Timezone-aware usage limits (user's local timezone)
- Edge to Node.js runtime migration for generate API
- Tiered access priority: subscription > credits > free
- Atomic credit deduction via SQL WHERE clause

**Issues Resolved:**

- OAuth callback flow with user sync
- Race conditions in usage increment/decrement
- Session persistence across pages
- Stripe webhook idempotency
- Edge runtime limitations with Supabase

**Issues Deferred:**

- Facebook OAuth (requires 6+ resubmissions)
- Google OAuth production verification (requires 3-7 day review)
- Annual billing with discount
- Usage alerts via email

**Technical Debt Incurred:**

- 3 missing VERIFICATION.md files (phases 04, 05, 08) - process documentation only
- Subscription quota counts saved posts, not generations (documented design decision)
