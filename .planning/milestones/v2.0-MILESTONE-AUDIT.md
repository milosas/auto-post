**Design Decision: Subscription Quota Model**

The subscription quota (Starter: 30/month, Pro: 70/month) counts saved posts, not generations. Users can generate unlimited text but can only save up to their quota.

- **Current behavior:** Count incremented when user saves post, not when generating
- **Impact:** Low - Unlimited plan has no quota, free users have daily limit
- **Status:** Documented design decision, not a bug
