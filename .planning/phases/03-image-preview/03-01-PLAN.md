   - Validate required fields (industry, prompt)

   - Call OpenAI DALL-E 3 API using existing openai client from `@/app/lib/ai.ts`:

     const openaiClient = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

       n: 1

   - All error messages in Lithuanian
