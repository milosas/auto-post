<task type="auto">
  <name>Task 1: Create posts collection API route (POST + GET)</name>
  <files>app/api/posts/route.ts</files>
  <action>
Create `app/api/posts/route.ts` with POST and GET handlers:

**POST /api/posts (Save post)**

1. Use Edge Runtime for consistency with existing API routes
2. Get authenticated user via `createClient()` from `@/lib/supabase/server`
3. If no user, return 401 Unauthorized
4. Parse request body: `{ text: string, dalleImageUrl?: string, config: GenerationConfig }`
5. Get internal userId by querying users table with auth user id
6. If dalleImageUrl provided:
   - Call `uploadDalleImage(dalleImageUrl, userId.toString(), Date.now().toString())`
   - Store returned permanent URL
7. Call `createPost(userId, text, permanentImageUrl, config)`
8. Return `{ postId: number }` with status 201

Request body type:
```typescript
interface SavePostRequest {
  text: string;
  dalleImageUrl?: string; // Temporary DALL-E URL (will be re-uploaded)
  config: GenerationConfig;
}
```

**GET /api/posts (List posts)**

1. Get authenticated user
2. If no user, return 401 Unauthorized
3. Get internal userId
4. Parse query params: `cursor`, `search`, `favorites` (boolean)
5. Call `getUserPosts(userId, cursor, search, favorites)`
6. Return `{ posts: Post[], nextCursor: number | null }`

Error handling:
- 400 for validation errors (missing text or config)
- 401 for unauthenticated requests
- 404 if user not found in database
- 500 for unexpected errors

Add CORS headers and proper Content-Type.

Create `app/api/posts/[id]/route.ts` with GET, PATCH, DELETE handlers:

**GET /api/posts/[id] (Post detail)**

1. Get authenticated user
2. Parse id from route params (convert to number)
3. Get internal userId
4. Call `getPostById(id, userId)` - includes authorization check
5. If not found, return 404
6. Return post object

**PATCH /api/posts/[id] (Toggle favorite)**

1. Get authenticated user
2. Parse id from route params
3. Get internal userId
4. Call `toggleFavorite(id, userId)`
5. Return `{ isFavorite: boolean }` with new state

**DELETE /api/posts/[id] (Soft delete)**

1. Get authenticated user
2. Parse id from route params
3. Get internal userId
4. Call `softDeletePost(id, userId)`
5. Return 204 No Content

All handlers:
- Use Edge Runtime
- Return 401 if not authenticated
- Return 404 if post not found or doesn't belong to user
- Handle errors gracefully
