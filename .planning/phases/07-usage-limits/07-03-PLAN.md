    Modify app/api/generate/route.ts to check and increment usage quota:

    **IMPORTANT:** The generate route uses Edge Runtime for streaming. However, the usage queries use Drizzle ORM which requires Node.js. Two options:

    Option A (Recommended): Keep Edge Runtime for generate, call a separate internal API
    Option B: Switch to Node.js runtime (loses 25s → 10s timeout benefit)

    **Implement Option A** - Call usage increment via internal fetch:

    1. After rate limit check and body validation, add usage quota check:
       ```typescript
       // 2.5. Check usage quota for authenticated users
       // Note: Get auth token from cookie/header if available
       const authHeader = request.headers.get('Authorization');
       const cookieHeader = request.headers.get('Cookie');

       if (authHeader || cookieHeader) {
         // User might be authenticated - check quota
         const timezone = request.headers.get('X-Timezone') || 'UTC';

         try {
           const usageResponse = await fetch(new URL('/api/usage', request.url), {
             method: 'POST',
             headers: {
               'Content-Type': 'application/json',
               'X-Timezone': timezone,
               // Forward auth cookies
               ...(cookieHeader ? { 'Cookie': cookieHeader } : {}),
               ...(authHeader ? { 'Authorization': authHeader } : {}),
             },
           });

           if (usageResponse.status === 401) {
             // Not authenticated - require login for generation
             return Response.json(
               {
                 error: 'auth_required',
                 message: 'Prisijunkite, kad galėtumėte generuoti įrašus'
               },
               { status: 401 }
             );
           }

           if (usageResponse.status === 429) {
             // Quota exceeded
             const usageData = await usageResponse.json();
             return Response.json(
               {
                 error: 'quota_exceeded',
                 message: 'Dienos limitas pasiektas. Atnaujinkite planą arba palaukite iki rytojaus.',
                 used: usageData.used,
                 limit: usageData.limit,
                 resetAt: usageData.resetAt
               },
               { status: 429 }
             );
           }

           if (!usageResponse.ok) {
             console.error('Usage check failed:', usageResponse.status);
             // Continue with generation on usage API failure (graceful degradation)
           }
         } catch (error) {
           console.error('Usage check error:', error);
           // Continue with generation on error (graceful degradation)
         }
       } else {
         // No auth headers - require login
         return Response.json(
           {
             error: 'auth_required',
             message: 'Prisijunkite, kad galėtumėte generuoti įrašus'
           },
           { status: 401 }
         );
       }
       ```

    2. Position this check AFTER rate limit check (line ~412) and BEFORE body validation/generation.
