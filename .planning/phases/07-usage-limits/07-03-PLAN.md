  <action>
    Modify app/api/generate/route.ts to check and increment usage quota:

    **RUNTIME CHANGE REQUIRED:** Switch from Edge Runtime to Node.js Runtime.

    **Why Node.js instead of keeping Edge?**
    - Edge-to-Node internal fetch loses Supabase session context (cookies don't forward properly between runtimes)
    - Node.js supports streaming just fine (ReadableStream works in Node.js)
    - Drizzle ORM works directly without needing internal API calls
    - The 25s Edge timeout is rarely hit in practice (typical generation: 5-15s)
    - Simpler architecture, easier to debug

    **Step 1: Change runtime declaration** (at top of file):
    ```typescript
    // Remove: export const runtime = 'edge';
    // Add:
    export const runtime = 'nodejs';
    export const maxDuration = 60; // 60 second timeout for Node.js (Vercel Pro)
    ```

    **Step 2: Add direct usage check** (imports and logic):
    ```typescript
    // Add imports at top
    import { createClient } from '@/lib/supabase/server';
    import { db } from '@/app/db';
    import { users } from '@/app/db/schema';
    import { eq } from 'drizzle-orm';
    import { checkAndIncrementUsage } from '@/lib/usage/queries';

    // After rate limit check, add usage quota check:
    // 2.5. Check usage quota for authenticated users
    const supabase = await createClient();
    const { data: { user: authUser } } = await supabase.auth.getUser();

    if (!authUser) {
      return Response.json(
        {
          error: 'auth_required',
          message: 'Prisijunkite, kad galėtumėte generuoti įrašus'
        },
        { status: 401 }
      );
    }

    // Get internal user ID
    const [dbUser] = await db.select().from(users).where(eq(users.authId, authUser.id));
    if (!dbUser) {
      return Response.json(
        { error: 'user_not_found', message: 'Vartotojas nerastas' },
        { status: 404 }
      );
    }

    // Check and increment usage
    const timezone = request.headers.get('X-Timezone') || 'UTC';
    const usageResult = await checkAndIncrementUsage(dbUser.id, timezone);

    if (!usageResult.allowed) {
      return Response.json(
        {
          error: 'quota_exceeded',
          message: 'Dienos limitas pasiektas. Atnaujinkite planą arba palaukite iki rytojaus.',
          used: usageResult.used,
          limit: usageResult.limit,
          resetAt: usageResult.resetAt?.toISOString()
        },
        { status: 429 }
      );
    }
    ```

    **Step 3: Position this check** AFTER rate limit check and BEFORE body validation/generation.
