<decisions>
## Implementation Decisions

### Dashboard Content
- Minimal stats approach — clean, not cluttered
- Required stats: generations today, total posts saved, subscription/credit status
- Additional stat: favorites count
- No recent activity preview or charts

### Industry Selector Fix
- Clicking on selected industry re-opens the dropdown
- User can change selection without clearing first
- Standard combobox behavior

### Claude's Discretion
- Dashboard layout (cards, sections, visual hierarchy)
- Post-login redirect destination (dashboard vs generator)
- Navigation structure between dashboard, generator, history
- Stats card styling and information density
- Mobile responsiveness approach

</decisions>
