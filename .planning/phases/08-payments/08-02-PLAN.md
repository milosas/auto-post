<task type="auto">
  <name>Task 3: Create credit package purchase API route</name>
  <files>app/api/stripe/credits/route.ts</files>
  <action>
Create POST handler for credit package purchase:

1. Authenticate user via Supabase
2. Get internal user ID from database
3. Accept `packageId` in request body ('10', '30', or '100')
4. Validate packageId exists in CREDIT_PACKAGES
5. Get or create Stripe customer (same logic as subscription checkout)
6. Create Checkout Session with:
   - `mode: 'payment'` (one-time, NOT subscription)
   - `customer: customerId`
   - `line_items: [{ price: package.priceId, quantity: 1 }]`
   - `success_url: '/?credits=success'`
   - `cancel_url: '/pricing?credits=canceled'`
   - `metadata: { userId, credits: package.credits.toString(), type: 'credit_purchase' }`
7. Return session URL

The `type: 'credit_purchase'` metadata helps webhook handler distinguish credit purchases from subscriptions.

Error handling:
- 401 if not authenticated
- 400 if packageId missing or invalid
  </action>
